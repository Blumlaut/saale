Saale agent

This computer is not paired with a Saale instance yet.

Open Settings → Integrations → This computer in Saale, get a pairing code, and press Open in the desktop app. That pairs this machine and opens Saale here. The instance travels with that link, so there is nothing to type.

Nothing happens when you press it? Start this app once (you are looking at it), then press the button again: the first run registers the handler for saale:// links.

No Saale within reach: saale-agent --url <instance> opens it, and saale-agent pair --url <instance> --code <code> pairs without a window.
